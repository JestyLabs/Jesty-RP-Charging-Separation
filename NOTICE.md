## Research and attribution

A substantial part of this project is device investigation: Retroid charging controls, process-recovery behavior, firmware differences, power-flow validation and process-protection testing.

The repository history, validation notes and [research provenance](PROVENANCE.md) are public so others can verify and build on that work.

If you reuse a non-trivial investigation, result, test method or implementation from this project, please credit **Jesty RP Charging Separation / Jesty Labs** and link back to this repository. This attribution request does not add restrictions to GPL-licensed code; it exists to preserve clear technical provenance and make collaboration easier.
