# Jesty RP Charging Separation 1.4.0

This update gives the app its final Jesty branding and approved device artwork
without changing the charging-control path.

## What changed

- Added the final transparent Jesty RP Charging Separation lockup.
- Added the approved separation and normal-charging dashboard artwork.
- Kept the app lockup aligned to the left of the control panel.
- Added compact Support and GitHub actions in the top-right corner.
- Added the open-source message in the bottom-right, with the support line
  first and the Jesty message in yellow.
- Updated the charging-separation toggle to the yellow Jesty accent.
- Expanded the AI-assistance disclosure to cover supervised code and visual
  development.

## What did not change

The Retroid Binder control path, capability detection, battery/USB monitoring,
safety fallback, boot restoration, and hardware charging logic are unchanged
from 1.3.0.
