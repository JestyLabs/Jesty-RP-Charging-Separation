# Jesty RP Charging Separation 1.5.3

The current charging status now appears immediately above the LIVE DASHBOARD
on wide landscape screens. On narrow screens it remains above the controls.
Charging behavior and saved settings are unchanged from v1.5.2.

The README also includes maintainer-supplied Flip 2 screenshots of v1.5.2 in
RIGHT AWAY mode and while charging toward an 80% stop level. The screenshots
document the layout and displayed state; they do not show a full automatic
stop/resume cycle.

## Verification

- Java charge-limit policy test and Android build passed.
- ZIP alignment, package `com.jesty.rpchargingseparation`, version `1.5.3`
  (`versionCode 22`), APK Signature Scheme v3, and the existing signing
  certificate were verified.
- The new status placement has not yet been visually checked on a Retroid.
